# NAAIL Scientific Discovery Protocol

**Researcher:** Saeid Homayoun — ORCID 0000-0002-2536-0446

This repository adopts the NAAIL scientific protocol for original research extensions:

**Literature → Co-Scientist Hypothesis Arena → ERA Empirical Design → AlphaEvolve/Computational Discovery → latent-structure analysis → AI-to-AI critic/defender/replicator → robustness and falsification → temporal/OOS validation → Chain-of-Evidence → DAG Governance → Human Gate.**

Rules: agent consensus is not truth; model confidence is not evidence; do not optimize for p-values; retain failed runs; prevent train/test and temporal leakage; distinguish prediction from causal identification; cite authoritative sources; require reproducibility and human approval before scientific discovery claims.
